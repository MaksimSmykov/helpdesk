# IT Navigator — руководство для сотрудников

**IT Navigator** — личный кабинет сотрудника по IT-вопросам. Здесь можно:

- посмотреть свой профиль и устройства;
- пройти диагностику, если что-то не работает;
- найти инструкцию в базе знаний;
- создать и отследить заявку в IT;
- развивать цифровые навыки (2FA, VPN, браузер, почта).

---

## Как устроен интерфейс

Слева — **постоянное меню**. Справа — содержимое выбранного раздела.

### Раздел «Кабинет»

| Пункт меню | Что внутри |
| --- | --- |
| **Профиль** | Ваши данные, контакты, рабочее место |
| **Устройства** | Ноутбук и техника, закреплённая за вами |
| **Навыки** | Чек-листы по цифровым инструментам и прогресс |
| **Мои заявки** | Список обращений в IT и их статусы |

### Раздел «Помощь»

| Пункт меню | Что внутри |
| --- | --- |
| **Нужна помощь** | Пошаговая диагностика «что не работает» |
| **База знаний** | Инструкции для самостоятельного решения |
| **Создать заявку** | Форма обращения к специалисту |

Внизу меню есть кнопка **«Нужна помощь»** — быстрый переход к диагностике.

---

## Профиль

Открывается сразу при входе (главная страница).

Здесь видно:

- ФИО, должность, отдел;
- email, телефон, внутренний номер;
- рабочее место и локация;
- ноутбук, подключённое устройство, сетевой профиль.

Эти данные помогают IT быстрее понять, с какого места и устройства вы работаете. Если что-то указано неверно — сообщите в IT или укажите это в заявке.

---

## Устройства

Список техники, закреплённой за вами:

- название и инвентарный номер;
- статус (например, «В работе»).

Перед сдачей устройства в IT удобно свериться с этим списком и сохранить рабочие файлы.

---

## Навыки

Раздел показывает, насколько вы освоили базовые IT-навыки компании. Примеры:

- безопасный вход с **2FA**;
- удалённый доступ через **VPN**;
- актуальный **браузер**;
- **корпоративная почта**.

### Как пользоваться

1. Выберите навык в списке сверху.
2. Ниже откроются шаги, прогресс и выбранная настройка.
3. Отмечайте выполненные шаги галочками — шкала прогресса обновится.
4. Если шаг непонятен, нажмите **«Инструкция по шагу»** — откроется нужная статья в базе знаний.
5. Можно добавить свой шаг в чек-лист.
6. Если шаг не получается — **«Не получается — создать заявку»**.

Когда все шаги отмечены, навык считается освоенным.

---

## Мои заявки

Список ваших обращений в IT.

Можно:

- искать по теме или номеру;
- фильтровать по статусу и приоритету;
- открыть карточку заявки и посмотреть детали.

### Статусы заявки

| Статус | Что значит |
| --- | --- |
| **Принято** | Заявка зарегистрирована |
| **Назначен специалист** | Заявкой занимается сотрудник IT |
| **Диагностика** | Идёт проверка причины |
| **Ожидается действие** | Нужен ответ или действие с вашей стороны |
| **Решено** | Проблема закрыта |

В карточке заявки показаны:

- описание проблемы;
- текущий статус и приоритет;
- исполнитель и срок;
- устройство;
- шкала прогресса по статусам;
- история изменений.

## Нужна помощь (диагностика)

Используйте, если что-то не работает и непонятно, с чего начать.

1. Выберите категорию: вход, сеть/VPN, программа, доступ, устройство и т.д.
2. Ответьте на несколько коротких вопросов.
3. Выполните предложенные проверки.
4. Если помогло — отметьте, что проблема решена.
5. Если нет — передайте специалисту: заявка создастся уже с результатами диагностики.

Так IT получает не «просто не работает», а понятный контекст.

## База знаний

Готовые инструкции по типовым ситуациям. Например:

- сброс пароля;
- подключение VPN;
- настройка 2FA;
- Teams, Outlook, браузер;
- доступ к папкам;
- установка программ.

### Как искать

- введите слово в строку поиска (VPN, пароль, почта, Teams…);
- или выберите категорию фильтрами.

Если статья помогла — нажмите **«Полезно»**.  
Если нет — **«Не помогло — создать заявку»**.

Ссылки **«Инструкция по шагу»** из раздела «Навыки» открывают сразу нужную статью.

---

## Создать заявку

Когда сразу нужна помощь специалиста или диагностика/статья не помогли.

Заполните:

- тему;
- категорию;
- устройство (если известно);
- описание проблемы;
- файл или скриншот — по возможности.

После отправки заявка появится в **«Мои заявки»**.

---

## Рекомендуемый порядок действий

1. **База знаний** или **Нужна помощь** — попробуйте решить сами.  
2. Если не получилось — **Создать заявку** (лучше после диагностики: в заявке уже будет контекст).  
3. Следите за статусом в **Мои заявки**.  
4. Параллельно закрывайте шаги в **Навыках**, чтобы типовые действия давались быстрее.
